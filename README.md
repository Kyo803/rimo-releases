# Rimo downloads

Windows installers for Rimo, a local-first desktop workbench.

**Source code is private. This repository publishes installers only.**

- [Download Rimo 0.3.0](https://github.com/Kyo803/rimo-releases/releases/tag/v0.3.0)
- [Latest installer](https://github.com/Kyo803/rimo-releases/releases/latest)
- Windows 10/11 x64
- Installers are unsigned; SmartScreen may ask for confirmation
- First launch creates `~/Desktop/Rimo`

## What is new in 0.3.0

Canvas refinement: hover to enlarge and scroll long notes, a full-screen reader,
task nodes with completion checkboxes, checklist progress, and device image
import. Photos are compressed for the board while the original is kept whole in
the vault; an optional Rimo image server can share the untouched original with
another desktop.

Rimo does not require an account, does not include telemetry and does not call
the network on launch. Optional online features are opt-in.
