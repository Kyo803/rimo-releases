# Rimo downloads

Windows installers for Rimo, a local-first desktop workbench.

**Source code is private. This repository publishes installers only.**

- [Download Rimo 0.11.0](https://github.com/Kyo803/rimo-releases/releases/tag/v0.11.0)
- [Latest installer](https://github.com/Kyo803/rimo-releases/releases/latest)
- Windows 10/11 x64
- Installers are unsigned; SmartScreen may ask for confirmation
- First launch opens the setup assistant and creates `~/Desktop/Rimo` or the folder you choose

## What is new in 0.11.0

Profiles are customizable: a display-name font, two-tone gradient, glow or
outline, an avatar decoration, a nameplate and a profile effect. Set a custom
status with an emoji and expiry, pronouns, a tagline and a bio. Profile cards
show badges, mutual chats and member-since, and the editor lists linked devices.

Built-in catalogs: four name fonts, six avatar decorations, five nameplates and
four profile effects, with a live preview and inventory pickers.

Chat message bodies, reactions and attachments remain end-to-end encrypted.
Profile images and customization metadata are public to signed-in accounts.
Device revocation, portable key backup, per-message forward secrecy and
voice/video calls are later work.

Also included since 0.6.0: first-run onboarding, sandboxed custom widgets, the
detective canvas, the GitHub tracker, the ledger chat design and a local SQLite
vault.

Rimo does not require an account, does not include telemetry and does not call
the network on launch. Chat and the GitHub tracker are opt-in; everything else
stays in your vault.
